# Workflows desativados

Cópia pública (portfólio) do Space Sports. Os workflows de deploy do staging na AWS
(`deploy-staging.yml`) e de build do app no EAS (`eas-build.yml`) ficam aqui, fora de
`.github/workflows/`, para que o GitHub **não os execute** neste repositório. Eles são mantidos
só como referência e porque os testes do `infra/` validam o conteúdo do `deploy-staging.yml`.

Os identificadores de infraestrutura deste repositório (conta AWS, OIDC do GitHub) são fictícios.
